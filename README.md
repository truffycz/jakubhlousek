# Jakub Hloušek – portfolio

Osobní portfolio: střih videa, grafika pro tisk i sítě, správa webu a články.

Web: https://jakubhlousek.github.io

## Obsah složky

| Soubor | Co to je |
|---|---|
| `index.html` | celé portfolio (jedna stránka) |
| `jakub-hlousek-cv.pdf` | životopis ke stažení (tlačítko „Stáhnout CV“) |
| `images/` | fotka a ukázky prací |
| `.nojekyll` | technický soubor pro GitHub Pages, nemazat |

## Jak přidat novou práci

1. Obrázek nahraj do složky `images/` (JPG, ideálně do 1200 px šířky).
2. V `index.html` zkopíruj existující `<article>…</article>` ve správné sekci (Video / Grafika / Web a psaní) a přepiš texty a cestu k obrázku.
3. Ulož (commit) – web se sám aktualizuje do minuty.
